# caesar-cipher

시저 암호로 글자를 암호화하는 C 프로그램입니다. 단계별로 기능을 늘려가며 만들고 있습니다.

## 현재 기능 (1단계)
- 대문자 한 글자와 미는 칸 수를 입력받아 암호화
- 예: H, 3 → K
- 예: X, 3 → A (Z 다음에 A로 돌아감)

## 원리
- 글자는 아스키코드 숫자로 저장됨 ('A' = 65)
- (글자 - 'A' + key) % 26 으로 알파벳 안에서 순환

## 한계
- 대문자만 지원 (소문자, 음수 key는 아직 처리하지 않음)

## 진행 계획
- [x] 1단계: 글자 하나 암호화
- [ ] 2단계: 문자열 전체 암호화
- [ ] 3단계: 복호화
- [ ] 4단계: 메뉴 (함수로 분리)
- [ ] 5단계: 파일 입출력

## 환경
- C, Visual Studio, Windows
